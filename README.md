# 麻酔薬リファレンス (masui_ref)

麻酔科ローテ中の研修医向けの Flutter アプリ。元データは `ますい.xlsx`（麻酔薬リファレンス）に準拠。

## 機能

### 1. 薬剤リファレンス（薬剤タブ）
- 31剤を収載（鎮静薬・筋弛緩薬・オピオイド・鎮痛/制吐・昇圧/カテコラミン・血管拡張・抗凝固/中和）
- 一般名・商品名・作用機序での**検索**、**カテゴリ別フィルタ**
- 詳細画面：規格／希釈／濃度／用法・用量／作用機序＋研修医向けの臨床メモ（薬物動態・一般的性質・副作用・禁忌など）

収載薬剤：プロポフォール, チオペンタール, チアラミラール, ミダゾラム, レミマゾラム,
デクスメデトミジン, フルマゼニル, ロクロニウム, スガマデクス, フェンタニル,
レミフェンタニル, モルヒネ, ペンタゾシン, ナロキソン, ドロペリドール,
アセトアミノフェン, フルルビプロフェン, フェニレフリン, エフェドリン,
アドレナリン, ノルアドレナリン, バソプレシン, ドパミン, ドブタミン,
ランジオロール, ニカルジピン, ニトログリセリン, ニコランジル,
アルプロスタジル, ヘパリン, プロタミン

### 2. γ計算機（γ計算タブ）
薬剤量(mg) / 総液量(ml) / 体重(kg) を入力し、
**流量(ml/h) ⇄ γ(mcg/kg/min)** を相互変換。
γ・mg/kg/h・mg/h・mg/day をまとめて表示。

換算式：
- 濃度[mcg/ml] = 薬剤量[mg] × 1000 / 総液量[ml]
- ml/h = γ × 体重[kg] × 60 / 濃度[mcg/ml]
- γ = ml/h × 濃度[mcg/ml] / (体重[kg] × 60)

（例）150mg/50ml・60kg・3ml/h → 2.5γ ＝ Excel の値と一致。

### 3. 解説（解説タブ）
NutriCalc の「ノート」と同じUI（カテゴリ色グリッド＋ドラッグで伸縮する本文パネル＋`■見出し`セクション）。
麻酔の考え方をトピック別にまとめたコラム。カテゴリ：全般／鎮静／鎮痛・オピオイド／筋弛緩／循環作動薬／モニタリング／薬理学／緊急対応。
（BIS・術中覚醒・筋弛緩の考え方・TOF/PTC・分布容積・NMDA興奮毒性・昇圧薬の等価換算・アナフィラキシー・アスピリン喘息 など）

## 構成
```
lib/
  main.dart                       # アプリ起点・ボトムナビ（薬剤／γ計算／解説）
  models/drug.dart                # Drug / DrugNote / DrugCategory
  data/drugs.dart                 # 31剤のデータ
  data/columns.dart               # コラム記事データ
  screens/
    drug_list_screen.dart         # 一覧（検索・フィルタ）
    drug_detail_screen.dart       # 詳細
    gamma_calculator_screen.dart  # γ計算機
    column_screen.dart            # 解説（コラム）
```

## 実行
```sh
flutter run -d chrome      # Web
flutter run                # 実機（iOS/Android）
flutter build web          # Webビルド
```
